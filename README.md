# Storage Converter (GB to MB)

## Purpose
This is a simple Python program designed to convert storage capacity from Gigabytes (GB) to Megabytes (MB) using the standard binary conversion rate (1 GB = 1024 MB).

## How to Run the Program
1. Ensure you have Python installed on your system.
2. Open your terminal or command prompt.
3. Navigate to the directory containing the script.
4. Run the program using the following command:
   ```bash
   python converter.py
   ```

## Example Input / Output
**Input:**
```
Enter storage in GB: 10.5
```

**Output:**
```
Storage in MB: 10752.0
```
